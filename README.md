# rooparestro
A modern restaurant landing page project designed using HTML, CSS, and JavaScript.rooparestro is a responsive and visually appealing restaurant landing page. This project is perfect for showcasing a restaurant’s branding, menu, and essential information. The design features prominent titles, a call-to-action button, and interactive food menu images.
Features
Responsive layout for desktop and mobile
Stylish restaurant branding and theme
Interactive "Check out Menu" button
Sections for Home, Menu, About, Location, and Contact
Highlighted menu items with images
